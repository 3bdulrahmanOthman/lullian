# Source Precedence Contract

Default ordering for conflict resolution:
1. explicit current project-owner/user intent for desired behavior/preferences;
2. observed repository/project artifacts for existing behavior;
3. current official external documentation/standards for technical facts;
4. high-signal trusted secondary evidence;
5. inference;
6. assumption;
7. unknown.

A precedence rule does not erase the lower-ranked source. Preserve conflict and record why one source controls the particular claim. For legal/compliance or domain-specific rules, document the stricter authoritative source explicitly.
