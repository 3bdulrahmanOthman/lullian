# Tool Security

Tool security is an evidence chain: exact subject identity, trusted scanner identity, immutable snapshot, scan evidence, dependency evidence, capability/scope evidence, MCP surface when applicable, security review, admission plan, explicit approval, and post-install verification.

The current validated scanner baseline is NVIDIA SkillSpector 2.11.2. A newer scanner never inherits trust automatically.

MCP tool descriptions and annotations are metadata only. Lullian does not execute candidate tools during vetting.
